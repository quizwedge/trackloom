# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it privately to:

- trackloom@quizwedge.net

Please include:

- affected version/commit
- reproduction steps or proof of concept
- potential impact

Do not open a public issue for security vulnerabilities until disclosure is coordinated.

## Supported Versions

Security updates are provided on a best-effort basis for the latest `main` branch.
